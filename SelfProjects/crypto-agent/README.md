# Crypto Trading Research Agent

Agentic AI system built using:
- LangChain
- LangGraph
- LangSmith

## Capabilities
- Fetch BTC price
- Analyze market sentiment
- Retrieve crypto news
- Evaluate portfolio exposure
- Generate trading insight

## Architecture

User → Agent → Tools → Analysis → Recommendation

## Tools
- price_tool
- sentiment_tool
- news_tool
- portfolio_tool
